# 🗡️ Cave RPG - Python Dungeon Crawler

A classic, text-based fantasy role-playing game (RPG) built entirely in Python. Explore dangerous cave systems, fight monsters, manage your inventory, and try to survive the depths.

## 🚀 Features
* **Dynamic Combat System:** Health points (HP), turn-based attacks, and randomized damage mechanics.
* **Inventory Management:** Collect weapons, armor, and health potions to aid your journey.
* **Exploration:** Navigate through different rooms with unique descriptions and random encounters.

## 🛠️ Tech Stack
* **Language:** Python 3.x
* **Core Concepts:** Object-Oriented Programming (OOP) / Functional logic, control flow, and data structures.
* **Standard Modules:** `random`, `time` (for immersive text rendering).

## 🎮 How to Play
Make sure you have Python installed on your system. Clone the repository and run the main game file via your terminal:

```bash
python main.py
